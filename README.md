# Media Downloader Android — projeto inicial, NÃO é APK funcional

Projeto Android Studio nativo com WebView e interface adaptada da versão Windows 3.8. Possui seletor de arquivos Android e ponte de copiar texto.

**Limitação importante:** os mecanismos de download yt-dlp, conversão FFmpeg e transcrição Whisper para Android **NÃO estão integrados**. O botão de processamento avisa isso claramente. Não se trata de clone funcional nem APK pronto. Não há Android SDK/Gradle neste ambiente para compilar ou testar APK.

Abra a pasta no Android Studio com Android SDK 35 e Gradle compatível para compilar o projeto visual. Não utilize como substituto da versão Windows até implementar os mecanismos nativos.
